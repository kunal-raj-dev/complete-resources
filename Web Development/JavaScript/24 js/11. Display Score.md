# 🏆 11. Display Score & Final Polish

Welcome coders! 🌟 Yeh hamare Simon Says Project ka aakhri video hai. Ab jab game over hota hai, toh bas "Game Over" likhna kaafi nahi hai. Player ko uska **Score** dikhana hoga aur ek jordaar visual feedback dena hoga, jaise screen ka laal (red) hona! Let's complete the masterpiece! 🎨

## 💯 1. Score Display & Game Over Screen

Score calculate karna bahut hi aasan hai. Apna dimag lagao... jitne levels player ne cross kiye, wahi toh uska score hai! Toh humara `level` variable directly hamara score ban jayega!

**Code update in `checkAns` function:**

```javascript
function checkAns(idx) {
    if (userSeq[idx] === gameSeq[idx]) {
        if (userSeq.length == gameSeq.length) {
            setTimeout(levelUp, 1000);
        }
    } else {
        // Here we show the final score which is 'level'
        h2.innerHTML = `Game Over! Your score was <b>${level}</b> <br> Press any key to start.`;
        
        // Add red visual flash to the screen
        document.querySelector("body").style.backgroundColor = "red";
        setTimeout(function() {
            document.querySelector("body").style.backgroundColor = "white";
        }, 150);
        
        reset();
    }
}
```

### 🔴 Flash Effect on the Body
Jab wrong answer click hota hai, hum direct `body` element ka `backgroundColor` red karte hain. Aur `setTimeout` use karke exactly 150ms ke baad wapas `white` kar dete hain. Yeh player ko ek "Danger / Error" feel deta hai! 🔥

## 🧠 Conceptual Q&A

**Q: How to persist the high score across sessions?**
A: Iske liye hum Browser ka `localStorage` use kar sakte hain. Har `Game Over` par check karenge:
```javascript
let highScore = localStorage.getItem("highScore") || 0;
if (level > highScore) {
    localStorage.setItem("highScore", level);
    console.log("New High Score!");
}
```

**Q: What if we want to show a modal instead of changing the heading?**
A: Hum ek HTML `div` bana kar usko CSS se hide karke (e.g., `display: none`) rakh sakte hain. Wrong click par use `display: flex` karke screen ke upar ek modal dikha sakte hain jisme "Play Again" button ho!

### `app.js` (Final Masterpiece)
```javascript
let gameSeq = [];
let userSeq = [];
let btns = ["yellow", "red", "purple", "green"];

let started = false;
let level = 0;

let h2 = document.querySelector("h2");

document.addEventListener("keypress", function () {
    if (started == false) {
        started = true;
        levelUp();
    }
});

function gameFlash(btn) {
    btn.classList.add("flash");
    setTimeout(function () {
        btn.classList.remove("flash");
    }, 250);
}

function userFlash(btn) {
    btn.classList.add("userflash");
    setTimeout(function () {
        btn.classList.remove("userflash");
    }, 250);
}

function levelUp() {
    userSeq = [];
    level++;
    h2.innerText = `Level ${level}`;

    let randIdx = Math.floor(Math.random() * 4); // Fix: Math.random() * 4 (kyunki 4 colors hain)
    let randColor = btns[randIdx];
    let randBtn = document.querySelector(`.${randColor}`);
    
    gameSeq.push(randColor);
    gameFlash(randBtn);
}

function checkAns(idx) {
    if (userSeq[idx] === gameSeq[idx]) {
        if (userSeq.length == gameSeq.length) {
            setTimeout(levelUp, 1000);
        }
    } else {
        h2.innerHTML = `Game Over! Your score was <b>${level}</b> <br> Press any key to start.`;
        document.querySelector("body").style.backgroundColor = "red";
        setTimeout(function () {
            document.querySelector("body").style.backgroundColor = "white";
        }, 150);
        reset();
    }
}

function btnPress() {
    let btn = this;
    userFlash(btn);

    userColor = btn.getAttribute("id");
    userSeq.push(userColor);

    checkAns(userSeq.length - 1);
}

let allBtns = document.querySelectorAll(".btn");
for (btn of allBtns) {
    btn.addEventListener("click", btnPress);
}

function reset() {
    started = false;
    gameSeq = [];
    userSeq = [];
    level = 0;
}
```

## 🧠 Grand Conceptual Q&A: Entire Simon Says Project

**Q: List all DOM methods used in this project.**
A: `querySelector`, `querySelectorAll`, `addEventListener`, `getAttribute`, `classList.add`, `classList.remove`, `innerText`, `innerHTML`, inline `style` changes.

**Q: List all array methods used.**
A: Only `push()` array ko build karne ke liye, and `length` property checking ke liye.

**Q: What design patterns did we use?**
A: Humne ek Event-driven aur State-machine type flow banaya jisme data(state) UI changes (DOM render) drive kar raha hai. Yeh modern React / frontend frameworks ka core concept hai!

**Q: How would you add difficulty levels?**
A: `setTimeout` delay ko level ke sath dynamically decrease kar do! Jaise-jaise level badhega, flash speed badh jayegi! `let delay = 1000 - (level * 50);`

**Q: How would you make this multiplayer?**
A: Turn-based system jisme ek `player1` state ho aur `player2` state. Do alag scores track honge aur alternately turn assign hogi.
