## 🎮 What is Simon Says Game?

**Simon Says** ek classic memory skill game hai. Aapne bachpan mein shayad ye game physical format mein ya kisi app par khela hoga.

### History & Origin 📜
- **Inventors:** Ralph Baer aur Howard Morrison ne 1978 mein is game ko invent kiya tha.
- **Publisher:** Milton Bradley company ne isko pehli baar release kiya tha.
- **Concept:** Ye electronic game 4 different colored buttons (usually Red, Yellow, Green, Blue) ke saath aata tha, jo light up hote the aur sound play karte the.

### Real-life Party Game Version 🎈
"Simon Says" ek popular real-life party game bhi hai jahan ek leader ("Simon") commands deta hai (e.g., "Simon says touch your nose"). Agar leader ne "Simon says" bola, toh hi players ko command follow karna hota hai. Hamara game iska digital memory version hai.

## 📋 Rules of the Game

Game ka flow bohot simple but highly addictive hai. Yahan step-by-step gameplay diya gaya hai:

1. **Start:** Game start hota hai jab player kisi key ko press karta hai.
2. **Flash:** Game randomly ek color button ko flash (light up) karta hai (Level 1).
3. **Repeat:** Player ko same color button click karna hota hai.
4. **Level Up:** Agar player sahi click karta hai, toh Level up ho jata hai.
5. **Next Sequence:** Game pichle sequence ko yaad rakhta hai aur ek **naya random color add karta hai**.
   - Example: Level 1 -> 🔴
   - Example: Level 2 -> 🔴 + 🟢
   - Example: Level 3 -> 🔴 + 🟢 + 🔵
6. **Game Over:** Player ko starting se poora naya sequence repeat karna hota hai. Agar player koi bhi galat button press kar deta hai, toh game over ho jata hai!
7. **Score:** Aapka final score highest level reached ke equal hota hai.

### Game Flow Visualized 🗺️

```mermaid
flowchart TD
    A[Start Game (Press Any Key)] --> B[Level Up (Level = 1)]
    B --> C[Game generates random color & adds to Sequence]
    C --> D[Game flashes the sequence]
    D --> E[Wait for User Input]
    E --> F{Did User match Sequence?}
    F -- Yes --> G{Was it the last color of sequence?}
    G -- No --> E
    G -- Yes --> B
    F -- No --> H[Game Over! Show Score]
    H --> I[Press any key to Restart]
    I --> A
```

## 🧠 Conceptual Q&A: Game Logic Thinking

Code likhne se pehle as a software engineer sochna shuru karte hain. Interviewers aisi thought process check karte hain!

**Q: Game apne generated sequence ko aur user ki clicks ko kaise yaad rakhega?**
> **A:** Hum Arrays use karenge! Humhe do arrays chahiye honge:
> 1. `gameSeq = []` - Ye un colors ko store karega jo game generate kar raha hai.
> 2. `userSeq = []` - Ye un colors ko store karega jo user click kar raha hai har level pe.

**Q: Har baar naya color randomly kaise aayega?**
> **A:** Hamare paas 4 colors hain. Hum unhe ek array mein rakh sakte hain `['red', 'yellow', 'green', 'blue']`. Phir `Math.random()` aur `Math.floor()` ka use karke hum 0 se 3 tak ek random index generate karenge aur color pick karenge.

**Q: User jab click karega, toh hume kaise pata chalega ki woh sahi ja raha hai?**
> **A:** Hum array comparison ka use karenge. Jaise-jaise user click karega, hum `userSeq` mein color push karenge aur immediately check karenge ki `userSeq[i] === gameSeq[i]`. Agar false mila, toh wahin Game Over!

**Q: "Game Over" pe kya hoga?**
> **A:** Screen red flash karegi, "Game Over" message display hoga with final score (Level), aur hum variables ko reset kar denge (`gameSeq = []`, `userSeq = []`, `level = 0`) taaki naya game start ho sake.
