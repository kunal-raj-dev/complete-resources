# Topic 02: Bitwise Operations & Number Systems — Master Index

> **Domain:** Low-Level Binary Representation, Two's Complement Arithmetic, Bitwise Operators, Bitmasking, and Data Type Modifiers

---

## 📋 Topic Overview

This module explores how numbers and operations are executed at the lowest hardware level. It covers positional number system conversions between decimal and binary, CPU two's complement encoding for negative numbers, bitwise logic (`&`, `|`, `^`, `~`, `<<`, `>>`), and fundamental bitmask manipulation algorithms used in high-performance computing and interview problem-solving.
