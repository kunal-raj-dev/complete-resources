# Topic 17: Binary Trees — Master Index

> **Domain:** Hierarchical Data Structures, Tree Traversals, Height/Diameter Invariants, Morris Traversal, and Threaded Trees

---

## 📋 Topic Overview

This module covers Binary Tree architecture: recursive and iterative DFS (Preorder, Inorder, Postorder), BFS level order, height and diameter calculations, vertical coordinate mapping (Top View), lowest common ancestor, tree construction from preorder/inorder traversals, width indexing, and $O(1)$-space Morris traversals.
