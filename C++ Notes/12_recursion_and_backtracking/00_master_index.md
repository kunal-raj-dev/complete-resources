# Topic 12: Recursion & Backtracking — Master Index

> **Domain:** Self-Referential Functions, Call Stack Activation Frames, Exhaustive Search, Pruning, Divide & Conquer Sorting

---

## 📋 Topic Overview

Recursion and Backtracking represent the highest-yield paradigm in algorithmic problem-solving. This module covers the mathematical principle of induction, call stack execution, recursive tree branching, state exploration, choice restoration (backtracking), classical hard problems (N-Queens, Sudoku Solver, Rat in a Maze), and recursive divide-and-conquer sorting (Merge Sort, Quick Sort, Count Inversions).
