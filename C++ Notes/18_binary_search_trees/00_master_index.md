# Topic 18: Binary Search Trees (BST) — Master Index

> **Domain:** BST Property, Inorder Sorted Invariant, Range Propagation, Balanced Conversions, and Iterators

---

## 📋 Topic Overview

This module covers Binary Search Trees (BSTs): standard CRUD operations, balanced tree construction from sorted arrays, range verification, BST LCA, preorder reconstruction, merging BSTs, recovery of swapped nodes, maximum subtree size calculation, next-right pointer linking, and lazy BST iterators.
