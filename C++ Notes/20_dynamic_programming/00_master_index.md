# Topic 20: Dynamic Programming & Knapsack — Master Index

> **Domain:** Optimal Substructure, Overlapping Subproblems, Memoization vs Tabulation, 1D DP, and Knapsack Optimization

---

## 📋 Topic Overview

This module covers Dynamic Programming foundations and classical 1D/2D optimization problems: Fibonacci state transitions, Climbing Stairs, linear and circular House Robber, energy jump costs, Fractional Knapsack (Greedy comparison), and 0/1 Knapsack with 1D reverse-capacity space optimization.
