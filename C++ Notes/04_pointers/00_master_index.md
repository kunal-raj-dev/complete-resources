# Topic 04: Pointers & Memory Management — Master Index

> **Domain:** Memory Addressing, Direct Memory Manipulation, Indirection, Pointer Arithmetic, and Reference Passing

---

## 📋 Topic Overview

This module demystifies the lowest-level memory interface available in C++. It covers physical memory addressing, dereferencing semantics, double pointers, `nullptr` type safety, pointer arithmetic scaling, array decay equivalence, and the technical trade-offs between pointer passing and C++ reference passing.
